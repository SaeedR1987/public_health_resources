# Analysis Classes Overview

## Purpose

The QuantDataAnalysis class hierarchy provides R6 classes for performing statistical analysis, calculating indicators, and generating analytical outputs from standardized survey data. These classes implement domain-specific analytical methods and calculations.

## Base Class: QuantDataAnalysis

The `QuantDataAnalysis` class is the base class that defines common analytical functionality. It provides:

- Indicator calculation framework
- Weighted analysis support
- Disaggregation by subgroups
- Confidence interval calculation
- Analytical output formatting
- Result export capabilities
- Data Analysis Plan (DAP) management
- Reference to parent Data object

**Location**: `R/class_quant_data_analysis.R`

## Relationship to Data Classes

QuantDataAnalysis objects are **generated by and linked to Data objects**:

### 1. Created by Data Objects

Analysis objects are created using the `generate_data_analysis()` method in Data classes:

```r
# Data object generates domain-specific Analysis object
data <- HouseholdData$new(data = df, uuid = "uuid")
data$standardize()

# Generate analysis object with optional DAP
analysis <- data$generate_data_analysis(
  stage = "standardized",
  analysis_config = my_dap  # Optional Data Analysis Plan
)
```

### 2. Inherits Data Context

When an Analysis object is created, it receives key information from its parent Data object:

- **`parent_data_object`**: Reference back to the Data object that created it
- **`data_hash`**: Hash of the data snapshot for version tracking
- **`variable_map`**: Variable mapping configuration from parent
- **`value_map`**: Value mapping configuration from parent
- **`data_stage_name`**: Which data stage is being analyzed ("standardized" or "clean")
- **`design`**: Survey design object for weighted analysis (from HouseholdData)

This inheritance ensures analyses operate on the same data context as the parent.

### 3. Owns Data Analysis Plan (DAP) as a Log Object

Analysis objects have their own **`data_analysis_plan`** field, which is a **QuantDataAnalysisPlanLog** object (a subclass of Log):

- **`data_analysis_plan`**: A QuantDataAnalysisPlanLog object storing the planned analyses
- Provides schema enforcement and validation for analysis plans
- Ensures type safety (e.g., numeric multiplier, validated calculation types)
- Can be provided during initialization via the `dap` parameter (as a data frame that gets wrapped in a Log)
- Can be modified after creation using methods like:
  - `add_indicator_dap()` - Add indicators to the plan (uses the Log's add_indicator method)
  - `remove_indicator_dap()` - Remove indicators from the plan
  - `generate_dap_from_schema()` - Auto-generate DAP from indicator schema

The DAP is owned by the Analysis object and persists with it, enabling reproducible analysis workflows.

**Example:**
```r
# Create analysis object with DAP (as data frame)
analysis <- data$generate_data_analysis(
  stage = "clean",
  analysis_config = my_dap_df  # Data frame that gets wrapped in QuantDataAnalysisPlanLog
)

# Access the DAP as a Log object
analysis$data_analysis_plan  # This is a QuantDataAnalysisPlanLog object

# Access the underlying data frame
analysis$data_analysis_plan$log_df  # The actual data frame with indicators

# Add indicators (internally uses Log's add_indicator)
analysis$add_indicator_dap(
  indicator_name = "fcs_score", 
  calculation = "mean",
  var_name = "fcs",
  multiplier = 1,
  indicator_unit = "score"
)

# Remove indicators
analysis$remove_indicator_dap("old_indicator")

# Validate the plan
analysis$data_analysis_plan$validate()

# Generate DAP from schema
analysis$generate_dap_from_schema()
```

### 4. Workflow Integration

Analysis fits into the Data workflow after cleaning:

```
Data Object (clean)
    ↓
    generates →  Analysis Object
                     ↓
                 Analysis Object owns DAP
                     ↓
                 calculate_indicators()
                     ↓
                 statistical analysis
                     ↓
                 export results
```

**Complete Example:**
```r
# 1. Data object with full workflow
data <- HouseholdData$new(data = df, uuid = "uuid")
data$standardize()

# 2. Quality check and clean
quality <- data$generate_data_quality(stage = "standardized")
quality$run_quality_checks()
data$generate_cleaning_log()
data$clean()

# 3. Generate Analysis object (linked to Data)
analysis <- data$generate_data_analysis(
  stage = "clean",
  analysis_config = my_dap  # Optional
)

# 4. Analysis object owns its DAP (as a QuantDataAnalysisPlanLog)
analysis$data_analysis_plan  # This is a QuantDataAnalysisPlanLog object
analysis$data_analysis_plan$log_df  # The underlying data frame

# 5. Perform analysis
analysis$calculate_all_indicators()
analysis$export_results("analysis_results.xlsx")

# 6. Analysis can reference parent if needed
analysis$parent_data_object$dataset_name
```

### 5. Key Differences from Quality Objects

| Aspect | Quality Objects | Analysis Objects |
|--------|----------------|------------------|
| **Purpose** | Assess data quality | Calculate indicators and perform analysis |
| **When created** | Before cleaning | After cleaning |
| **Owns DAP** | No | Yes - `data_analysis_plan` field (QuantDataAnalysisPlanLog object) |
| **Output** | Quality flags and reports | Indicator tables and statistics |
| **References parent** | Yes - `parent_data_object` | Yes - `parent_data_object` |

See [Data Classes Overview](../Data_Classes/data_classes_overview.md) for more details on the parent-child relationship.

## Subclasses

### HealthAnalysis

Analytical class for health services and morbidity indicators.

**Purpose**: Calculate health-related indicators including illness prevalence, treatment seeking, and healthcare access.

**Key Indicators**:
- Illness prevalence (overall and by type)
- Treatment-seeking rate
- Healthcare facility utilization
- Consultation patterns
- Vaccination coverage (if applicable)

**Common Disaggregations**:
- Age group
- Sex
- Geographic area
- Socioeconomic status

**Location**: `R/class_quant_data_analysis_health.R`

---

### DemographicsAnalysis

Analytical class for demographic indicators.

**Purpose**: Calculate population structure and demographic indicators.

**Key Indicators**:
- Population distribution by age and sex
- Household size distribution
- Dependency ratio
- Sex ratio
- Age-sex pyramid generation
- Household composition

**Common Disaggregations**:
- Geographic area
- Urban/rural
- Household wealth quintile

**Location**: `R/class_quant_data_analysis_demographics.R`

---

### MortalityAnalysis

Analytical class for mortality indicators.

**Purpose**: Calculate mortality rates and analyze death patterns.

**Key Indicators**:
- Crude Death Rate (CDR)
- Under-5 Death Rate (U5DR)
- Age-specific death rates
- Cause-specific mortality
- Excess mortality

**Common Disaggregations**:
- Age group
- Sex
- Geographic area
- Time period

**Location**: `R/class_quant_data_analysis_mortality.R`

---

### WASHAnalysis

Analytical class for Water, Sanitation, and Hygiene indicators.

**Purpose**: Calculate WASH access and practice indicators.

**Key Indicators**:
- Access to improved water source
- Access to improved sanitation
- Handwashing facility with soap and water
- Water treatment practices
- WASH ladder classification
- Time to water source
- Water source reliability

**Common Disaggregations**:
- Geographic area
- Urban/rural
- Household wealth quintile
- Population density

**Location**: `R/class_quant_data_analysis_wash.R`

---

### NutritionAnalysis

Analytical class for nutrition and anthropometry indicators.

**Purpose**: Calculate nutritional status indicators and dietary patterns.

**Key Indicators**:
- Global Acute Malnutrition (GAM) prevalence
- Severe Acute Malnutrition (SAM) prevalence
- Chronic malnutrition (stunting) prevalence
- Underweight prevalence
- MUAC-based malnutrition prevalence
- Minimum Dietary Diversity (MDD)
- Minimum Meal Frequency (MMF)

**Common Disaggregations**:
- Age group (6-23 months, 6-59 months, etc.)
- Sex
- Geographic area
- Season

**Location**: `R/class_quant_data_analysis_nutrition.R`

---

### QuantDataAnalysisFSL

Analytical class for Food Security and Livelihoods indicators.

**Purpose**: Calculate food security and livelihood indicators.

**Key Indicators**:
- Food Consumption Score (FCS) distribution
- Household Dietary Diversity Score (HDDS)
- Reduced Coping Strategy Index (rCSI)
- Food insecurity prevalence (by category)
- Livelihood diversity
- Income sources
- Asset ownership

**Common Disaggregations**:
- Geographic area
- Livelihood zone
- Household wealth quintile
- Urban/rural

**Location**: `R/class_quant_data_analysis_fsl.R`

## Common Functionality

All Analysis classes inherit these core capabilities from the base `QuantDataAnalysis` class:

### 1. Initialization

```r
analysis <- HealthAnalysis$new(
  data = standardized_data_object,
  weights = "weight_column"
)
```

### 2. Indicator Calculation

```r
# Calculate specific indicators
analysis$calculate_prevalence(variable = "illness")
analysis$calculate_mean(variable = "age")
analysis$calculate_proportion(variable = "treatment_sought")
```

### 3. Disaggregation

```r
# Disaggregate by subgroups
analysis$disaggregate_by(
  variable = "illness_prevalence",
  by = c("age_group", "sex", "region")
)
```

### 4. Weighted Analysis

```r
# Apply survey weights
analysis$set_weights("survey_weight")
analysis$calculate_weighted_mean("fcs_score")
```

### 5. Confidence Intervals

```r
# Calculate confidence intervals
analysis$calculate_ci(
  variable = "prevalence",
  confidence_level = 0.95
)
```

### 6. Export Results

```r
# Export analytical results
analysis$export_results(file = "analysis_results.xlsx")

# Export specific tables
analysis$export_table(table = "prevalence_by_age", file = "prevalence.csv")
```

## Analytical Methods

### 1. Prevalence Calculation

Calculate prevalence with confidence intervals:

```r
analysis$calculate_prevalence(
  variable = "malnutrition",
  by = "age_group",
  weights = "survey_weight"
)
```

### 2. Mean and Median

Calculate central tendency measures:

```r
# Weighted mean
analysis$calculate_mean(
  variable = "fcs_score",
  by = "region",
  weights = "survey_weight"
)

# Median
analysis$calculate_median(
  variable = "household_size",
  by = "urban_rural"
)
```

### 3. Distribution Analysis

Analyze distribution of variables:

```r
# Distribution by categories
analysis$calculate_distribution(
  variable = "fcs_category",
  by = "region"
)

# Percentiles
analysis$calculate_percentiles(
  variable = "income",
  percentiles = c(25, 50, 75)
)
```

### 4. Comparison and Testing

Compare groups and test differences:

```r
# Compare two groups
analysis$compare_groups(
  variable = "prevalence",
  group1 = "urban",
  group2 = "rural",
  test = "chi_square"
)

# Test trend
analysis$test_trend(
  variable = "prevalence",
  by = "time_period"
)
```

## Usage Patterns

### Basic Workflow

```r
# 1. Prepare data
data <- HouseholdData$new(data = df, uuid = "uuid")
data$set_variable_schema(schema)
data$standardize()
data$calculate_indicators()

# 2. Create analysis object
analysis <- DemographicsAnalysis$new(
  data = data,
  weights = "survey_weight"
)

# 3. Calculate indicators
analysis$calculate_all_indicators()

# 4. Disaggregate results
results <- analysis$disaggregate_by(
  indicators = c("household_size", "dependency_ratio"),
  by = c("region", "urban_rural")
)

# 5. Export results
analysis$export_results(file = "demographics_results.xlsx")
```

### Advanced Analysis

```r
# Multi-domain analysis
health_analysis <- HealthAnalysis$new(data = data, weights = "weight")
nutrition_analysis <- NutritionAnalysis$new(data = data, weights = "weight")

# Calculate indicators
health_results <- health_analysis$calculate_all_indicators()
nutrition_results <- nutrition_analysis$calculate_all_indicators()

# Cross-domain analysis
combined_analysis <- analysis$cross_tabulate(
  var1 = "malnutrition_status",
  var2 = "illness_last_2weeks",
  by = "age_group"
)
```

## Output Formats

Analysis classes support multiple output formats:

1. **Data frames**: For further manipulation in R
2. **Excel files**: For sharing and review
3. **CSV files**: For import into other tools
4. **JSON**: For web applications and APIs
5. **HTML tables**: For reports and presentations

## Key Design Principles

1. **Domain-specific**: Each subclass implements domain-specific calculations
2. **Survey weights**: Built-in support for weighted analysis
3. **Confidence intervals**: Automatic CI calculation for estimates
4. **Disaggregation**: Flexible subgroup analysis
5. **Standardized outputs**: Consistent output formats across domains
6. **Reproducible**: Clear documentation of analytical methods
